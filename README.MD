# Portfolio Ragil Fahrezi

Website portfolio untuk tugas Pemrograman Web kelas TEKOM D 25.

## Fitur
- Multi-page website: Home, About Me, Contact
- Dark/Light Mode dengan localStorage
- Typing effect pada halaman Home
- Greeting berdasarkan waktu
- Hobby & photo gallery dengan lightbox
- Validasi Contact Form menggunakan JavaScript
- Animasi reveal saat halaman dibuka/di-scroll
- Tombol Back to Top
- Responsive mobile navigation

## Struktur
```text
Web Porto/
├── index.html
├── about.html
├── contact.html
├── style.css
├── script.js
└── images/
    ├── football2.jpg
    ├── formal.jpg
    ├── futsal.jpg
    ├── gaming.jpg
    ├── hiking.jpg
    ├── Ragil.jpeg
    ├── RF.png
    ├── rf1.jpg
    ├── rf2.jpg
    └── running.jpg
```

Buka `index.html` di browser untuk menjalankan website.
